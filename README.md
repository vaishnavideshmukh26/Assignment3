Task 1: Calculate Factorial Using a Function

🔹 Problem Statement

Write a Python program that:

Defines a function named factorial that takes a number as an argument.

Calculates its factorial using a loop or recursion.

Returns the factorial value.

Calls the function with a sample number and prints the result.

📌 Sample Expected Output

If the function is called with the number 5, it should return:

The factorial of 5 is: 120

📁 File Name

Task1.py

✅ Task 2: Using the Math Module for Calculations

🔹 Problem Statement

Write a Python program that:

Takes a number as input from the user.

Uses the math module to calculate:

Square root

Natural logarithm (log base e)

Sine value (input considered in radians)

Displays the computed results clearly.

If the user enters 25, the output should be similar to:

Square root: 5.0
Natural Logarithm: 3.2188758248682006
Sine Value: -0.13235175009777303
